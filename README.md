# CARDTRADELIB

CARDTRADELIB 是一套以 Python / PySide6 製作的卡片庫存管理工具，主要用於管理實體卡牌庫存、銷售紀錄、MTG 卡片資料、Yuyu-tei 卡價查詢，以及露天賣場商品同步。

本專案目標是把「卡片資料查詢」、「本地庫存管理」、「銷售紀錄」、「賣場上架/同步」整合在同一個桌面程式中，減少手動整理 Excel、查價、上架與扣庫存的重複作業。

---

## 功能特色

### 一般卡片庫存管理

* 新增、修改、刪除卡片庫存
* 支援分類管理
* 支援買入方式管理
* 支援 PSA / BGS 標籤
* 支援圖片管理
* 支援銷售紀錄
* 自動計算成本、售價、手續費、利潤與 ROI
* 支援 CSV 匯出

---

### Scryfall 查詢

* 透過 Scryfall 查詢 MTG 卡片資料
* 支援卡名、系列、格式、顏色、稀有度、類型、語言篩選
* 支援本機 SQLite 快取
* 可建立 Scryfall 本機資料庫，加速後續搜尋
* 可將查詢結果加入 MTG庫存
* 支援表格檢視與卡圖檢視

---

### MTG庫存

* 管理從 Scryfall 加入的 MTG 卡片
* 支援數量、價格、系列、稀有度、語言等欄位
* 支援篩選、排序、修改、刪除
* 支援 CSV 匯出
* 可與露天賣場資料連動

---

### Yuyu-tei 查詢

* 透過 Yuyu-tei 公開頁面查詢卡片資料
* 支援大分類與小分類篩選
  例如：卡牌種類 > 卡牌期數
* 支援販售 / 買取模式
* 每次搜尋都重新讀取頁面，避免使用舊價格快取
* 搜尋結果會記錄價格讀取時間
* 可將查詢結果加入 Yuyu-tei庫存

---

### Yuyu-tei庫存

* 管理從 Yuyu-tei 加入的卡片資料
* 支援卡牌種類、期數、稀有度、價格、庫存狀態等欄位
* 支援表格檢視與卡圖檢視
* 支援修改、刪除、CSV 匯出
* 可與露天賣場資料連動

---

### 露天賣場連動

* 支援露天商品配對
* 支援露天商品上架與編輯
* 支援露天商品狀態同步
* 支援露天訂單套用至本地庫存
* 支援 MTG庫存 與 Yuyu-tei庫存來源
* 支援卡牌種類篩選
* 支援定位到來源庫存

---

### 授權與更新

* 支援授權金鑰啟用
* 支援定期檢查授權狀態
* 支援更新檢查
* 支援穩定版 EXE 替換流程

---
